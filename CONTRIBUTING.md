# Colaborar

Trabaja en una rama breve con un nombre descriptivo (`feat/contactos`, `fix/sesion`). Mantén TypeScript estricto, la interfaz en español y los límites entre UI, negocio y datos. Antes de proponer cambios ejecuta `npm run check`. Incluye migraciones y pruebas RLS cuando cambie el modelo de datos. Usa commits claros en imperativo y nunca subas secretos o datos personales.

La licencia está pendiente de decisión del propietario; contribuir no implica una licencia de redistribución hasta que se incorpore una.
